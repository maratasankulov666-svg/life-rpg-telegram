# Life RPG → Telegram Mini App: инструкция по шагам

Это подробная версия — без "просто задеплой", с каждым нажатием. Иди по
порядку, ничего не перескакивай.

---

## ЧАСТЬ 1. Создать бота в Telegram

1. Открой Telegram (телефон или десктоп — не важно).
2. В поиске введи `BotFather` и открой чат с ботом, у которого синяя галочка
   верификации и username `@BotFather`.
3. Нажми **Start** (или напиши `/start`), если это первый раз.
4. Напиши команду:
   ```
   /newbot
   ```
5. BotFather спросит **имя бота** (то, что видят люди, может быть на русском,
   с пробелами). Например: `Life RPG`. Напиши его и отправь.
6. BotFather спросит **username** — техническое имя, обязательно латиницей и
   обязательно заканчивается на `bot`. Например: `life_rpg_game_bot`. Если
   имя занято — напишет об этом, придумай другое и отправь снова.
7. Если всё ок, BotFather пришлёт сообщение вида:
   ```
   Done! Congratulations on your new bot...
   Use this token to access the HTTP API:
   123456789:AAExampleTokenLooksLikeThis
   ```
   **Скопируй этот токен и сохрани его** (например, в заметки) — он нам не
   понадобится прямо сейчас, но пригодится позже, если будешь добавлять бота
   для напоминаний.
8. Найди в Telegram своего нового бота по username, который ты придумал на
   шаге 6, и нажми **Start** — просто чтобы открыть с ним чат, дальше он
   пока пустой, это нормально.

Бот создан. Дальше — сайт, который откроется внутри него.

## ЧАСТЬ 2. Выложить код на GitHub

Если у тебя уже есть аккаунт GitHub и ты умеешь пользоваться git — можешь
пропустить в конец этой части и просто запушить папку из архива. Если нет —
делай через сайт, без единой команды в терминале.

1. Зайди на **github.com** → **Sign up**, если нет аккаунта. Придумай логин,
   почту, пароль. Подтверди почту по ссылке, которую пришлют на email.
2. После входа нажми зелёную кнопку **New** (или "+" в правом верхнем углу →
   **New repository**).
3. **Repository name**: напиши `life-rpg-telegram`.
4. Оставь **Public** (или Private — не важно, оба варианта подходят).
5. Не отмечай "Add a README file" — у нас он уже есть в архиве.
6. Нажми **Create repository**.
7. Откроется страница с инструкциями — нам нужен способ **"uploading an
   existing file"**. На этой же странице есть ссылка
   `uploading an existing file` — нажми на неё.
8. Распакуй архив `life-rpg-telegram.zip`, который я тебе прислал, у себя на
   компьютере (просто дважды кликнуть — на Windows/Mac архивы распаковываются
   стандартно).
9. Открой распакованную папку и **выдели все файлы и все папки внутри**
   (`index.html`, `package.json`, `vite.config.js`, `README.md`, папку `src`
   целиком) и перетащи их все в область на странице GitHub с надписью
   "Drag files here to add them to your repository".
10. Дождись, пока загрузка каждого файла закончится (внизу появится список
    с зелёными галочками).
11. Внизу страницы в поле **Commit changes** можно оставить текст по
    умолчанию.
12. Нажми зелёную кнопку **Commit changes**.

Код теперь лежит в твоём GitHub-репозитории. Дальше — хостинг.

## ЧАСТЬ 3. Задеплоить на Vercel

1. Зайди на **vercel.com**.
2. Нажми **Sign Up**.
3. Выбери **Continue with GitHub** — это самый простой вариант, он свяжет
   Vercel напрямую с твоим GitHub-аккаунтом.
4. Vercel попросит разрешение на доступ к GitHub — нажми **Authorize Vercel**.
5. После входа откроется дашборд Vercel. Нажми **Add New...** → **Project**
   (кнопка обычно в правом верхнем углу).
6. Появится список твоих GitHub-репозиториев. Найди `life-rpg-telegram` и
   нажми рядом с ним **Import**.
7. Откроется экран настройки проекта:
   - **Framework Preset** — Vercel обычно сам определяет "Vite", если нет —
     выбери его вручную из выпадающего списка.
   - Остальные поля (Build Command, Output Directory, Install Command)
     оставь как предложено по умолчанию — они уже правильные для Vite
     (`npm run build`, `dist`, `npm install`).
8. Нажми **Deploy**.
9. Начнётся сборка — займёт обычно 30–90 секунд. Будет видно лог сборки на
   экране.
10. Когда появится надпись **Congratulations!** и картинка с конфетти —
    деплой прошёл успешно.
11. Нажми на превью-картинку сайта или кнопку **Continue to Dashboard**, там
    в верхней части страницы будет ссылка вида:
    ```
    https://life-rpg-telegram-xxxxx.vercel.app
    ```
    **Скопируй именно эту ссылку** — она понадобится в следующей части.

Проверка (не обязательна, но полезна): открой эту ссылку в обычном браузере
на телефоне или компьютере — должна открыться игра. Она будет работать и
тут, просто автосохранение временно пойдёт не в CloudStorage (его вне
Telegram не существует), а в память браузера — это нормально, для реального
использования это неважно.

## ЧАСТЬ 4. Подключить сайт как кнопку в боте

1. Вернись в Telegram, в чат с **@BotFather**.
2. Напиши:
   ```
   /mybots
   ```
3. Появится список твоих ботов — нажми на того, что создал в Части 1
   (`life_rpg_game_bot` или как ты его назвал).
4. Нажми **Bot Settings**.
5. Нажми **Menu Button**.
6. Нажми **Configure Menu Button**.
7. BotFather попросит **ссылку** — пришли ту, что скопировал в конце Части 3
   (`https://life-rpg-telegram-xxxxx.vercel.app`).
8. Затем попросит **текст кнопки** — например, напиши `Играть` или `Open Game`.
9. Готово — BotFather подтвердит, что кнопка настроена.

---

## ЧАСТЬ 5. Проверить, что всё работает

1. Открой чат со своим ботом в Telegram (на телефоне — там Mini Apps
   работают полноценно, на десктопе тоже должно открыться).
2. Рядом с полем ввода сообщения (или через иконку меню слева от поля) должна
   появиться кнопка с текстом, который ты задал в шаге 8 предыдущей части.
3. Нажми на неё — игра должна открыться прямо внутри Telegram, на весь экран.
4. Пройди первые шаги (создай персонажа/выполни квест), закрой Mini App
   (просто закрой окно или свайпни вниз).
5. Открой её заново той же кнопкой — прогресс должен сохраниться. Это
   значит, что CloudStorage сработал.
6. Дополнительно можно зайти в игре в **Настройки** — там должен быть
   виден статус автосохранения и время последнего сохранения.

## Если что-то не открывается или не сохраняется

- **Кнопка меню не появляется** — подожди пару минут, иногда Telegram
  кэширует настройки бота; попробуй перезапустить приложение Telegram.
- **Игра открывается, но белый экран** — открой ту же ссылку из Части 3 в
  обычном браузере: если там тоже белый экран, проблема в сборке (пришли мне
  текст ошибки из лога сборки на Vercel — Deployments → последний деплой →
  вкладка "Build Logs").
- **Прогресс не сохраняется между открытиями** — значит CloudStorage не
  срабатывает; наиболее вероятная причина — Mini App открыт не через
  настоящую кнопку бота, а просто как обычная веб-страница (тогда
  `window.Telegram.WebApp` недоступен). Открывать нужно именно через кнопку
  внутри чата с ботом.

Когда дойдёшь до какого-то из этих шагов и что-то не заведётся с первого
раза — пришли, на каком именно шаге застрял и что видишь на экране, разберём
вместе.
